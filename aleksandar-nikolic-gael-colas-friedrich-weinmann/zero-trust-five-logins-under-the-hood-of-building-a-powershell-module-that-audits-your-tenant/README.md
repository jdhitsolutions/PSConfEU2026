# Zero Trust, Five Logins: Under the Hood of Building a PowerShell Module That Audits Your Tenant

## Abstract

One open-source PowerShell module. Hundreds of security checks. Five logins. (We'll explain.)

ZeroTrustAssessment audits your Entra ID, Intune, Azure networking, and Purview configs against Zero Trust best practices — and in this session, the people who built it will show you exactly how the sausage gets made.

We'll cover how we pull data across multiple APIs (we wished it was all Microsoft Graph — it wasn't), why we ended up embedding DuckDB — the one with the funny name — to run SQL analytics inside the module, and how to handle tenants so large your laptop fan sounds like a jet engine.

Mostly live demo. Mostly working. Come for the Zero Trust. Stay for the greasy details.
