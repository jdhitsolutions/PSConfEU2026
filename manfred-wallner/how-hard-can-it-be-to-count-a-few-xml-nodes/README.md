# How hard can it be to count a few XML nodes?

## Abstract

It turns out the answer depends a lot on the language, the parser, and the file size. etc.

PowerShell is usually written off when dealing with mutli-GB workloads, but actually is quite competitive when used correctly! Let's compare languages, parser models, and real-world tradeoffs - less about “which language is best” and more about how easily performance assumptions can fall apart once you start measuring.
