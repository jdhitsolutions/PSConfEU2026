# It Works On My Machine...So We Will Ship Your Machine. Devcontainers!

## Abstract

Development Containers (devcontainers) are a rapidly evolving way to use a container as a full-featured development environment. Come learn about: 
- the devcontainer open specification
- the many ways to define them
- the many ways to run them including locally using vscode, the devcontainer CLI, and GitHub Codespaces

Discover how devcontainers enable you to set up a common dev box for PowerShell, Python, Ansible, and many other kinds of environments so that your coworkers can hit the ground running, and you can pick up where you left off without trashing your work computer.
